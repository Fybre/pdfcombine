# PDF Combine

A small cross-platform (Windows / macOS) desktop tool for merging PDF files.

- Drag PDFs (or folders of PDFs) into the left pane, or use **Add PDFs…**
- Each file shows a first-page thumbnail and its page count
- Select a file to preview all of its pages on the right
- Reorder by dragging in the list, **▲ Up / ▼ Down**, or Ctrl+Up / Ctrl+Down
- **Remove** (or Delete key) / **Clear**
- **Save Combined PDF…** (Ctrl/Cmd+S) writes the files in list order
- Password-protected PDFs prompt for the password; the output is unencrypted

Built with PySide6 (Qt, LGPL) and pypdfium2 (PDFium, Apache-2.0/BSD).

## Building a standalone executable

PyInstaller cannot cross-compile, so build on each target OS.

| OS      | Command      | Output                                                  |
|---------|--------------|---------------------------------------------------------|
| macOS   | `./build.sh` | `dist/PDF Combine.app` and `dist/PDFCombine-macos.zip`  |
| Windows | `build.bat`  | `dist\PDFCombine.exe` (single file, no install needed)  |

Requires Python 3.10+.

## Automated builds and releases

`.github/workflows/build.yml` builds Windows x64, macOS Apple Silicon and macOS Intel on
every push and pull request (download them from the run's **Artifacts**). Pushing a version
tag publishes a GitHub Release with all three attached:

```
git tag v1.0.0 && git push origin v1.0.0
```

**macOS signing / notarization** happens automatically when these repository secrets are set
(otherwise the app is only ad-hoc signed):

| Secret | Value |
|--------|-------|
| `MACOS_CERTIFICATE` | Base64 of your *Developer ID Application* certificate exported as `.p12` |
| `MACOS_CERTIFICATE_PASSWORD` | The password you gave the `.p12` export |
| `APPLE_ID` | Your Apple ID email |
| `APPLE_TEAM_ID` | Your 10-character team ID |
| `APPLE_APP_PASSWORD` | An app-specific password from account.apple.com |

**Windows** builds are not code-signed, so SmartScreen shows "Windows protected your PC" the
first time - click **More info → Run anyway**.

## Running from source

```
pip install -r requirements.txt
python pdfcombine.py [files...]
```

## Icon

`assets/icon.{png,ico,icns}` are generated by `python tools/make_icon.py` (the `.icns`
needs macOS). Re-run it after editing the drawing code, then rebuild.
